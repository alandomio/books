# PUBLISH_CONFIG.md — CHRONOS: Ai Confini dell'Impero

This file feeds `generate_cover.sh` and `publish.sh`. It is the one place to
edit when customizing the cover art or the ebook/PDF metadata for THIS book —
never edit the scripts themselves for a per-book change.

`Title` and `Language` are intentionally NOT duplicated here: they are read
straight from `INSTRUCTION.md` § METADATA so there is a single source of
truth. Only fields that don't already live elsewhere go in this file.

**Bilingual note (deviation from the generic single-language template):** this
project publishes two editions (Italiano / Slovenščina) from `chapter_X_it.md`
/ `chapter_X_sl.md` pairs — see `publish.sh` § CUSTOMIZE PER PROJECT. Author,
Publisher and ISBN below apply to both editions; Description is given once in
Italian (edit `publish.sh` if a fully distinct Slovenian blurb is wanted).

## Cover Brief (used by generate_cover.sh)

This is the actual creative brief for the AI-generated cover artwork. Be
specific — vague briefs produce generic stock-photo-style covers.

- **Visual style:** Illustrazione digitale editoriale per libro di storia ragazzi (11-13 anni), linee pulite, non fotorealistica, non infantile — pensa a un poster da "reportage nel tempo", non a un cartone animato.
- **Mood & palette:** Blu notte e ottone/oro antico (l'estetica "cronoriporter/HUD" della serie CHRONOS), con un accento verde Carso/Carniola per bilanciare il blu marino di Trieste — nessun colore bandiera nazionale in primo piano.
- **Key symbolic elements:** una bussola/orologio HUD sovrapposto a una mappa storica dell'Alto Adriatico e della Carniola; il profilo di un porto (gru, vele) che sfuma in un profilo di boschi/carso; due sagome in controluce (Alex e Maja) che guardano lo stesso orizzonte da prospettive leggermente diverse.
- **What to avoid:** nessuna bandiera nazionale isolata (italiana o slovena) come simbolo dominante — il libro non è centrato su un'unica identità; niente iconografia da manuale scolastico generico (libri impilati, mappamondo); niente stile fumetto/cartoon.
- **Aspect ratio:** portrait ebook cover, 1600x2560 (1:1.6) — override in `generate_cover.sh` via `COVER_WIDTH`/`COVER_HEIGHT` env vars if targeting a different platform.

## Notes for the human customizing this file

- `Description` doubles as the pandoc EPUB metadata description AND is a
  reasonable draft for the actual store listing — refine before real publication.
- The cover generated by `generate_cover.sh` composites the Italian title
  (read from `INSTRUCTION.md`) by default. For a distinct Slovenian-titled
  cover, run it a second time with `INSTRUCTION.md`'s Title field temporarily
  swapped, or extend the script — not yet automated in this pass.
- If you regenerate the cover after editing the brief, run
  `./generate_cover.sh --force` (the script skips generation if `cover.png`
  already exists).
