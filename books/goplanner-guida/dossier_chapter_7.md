### § 1 — Che cosa legge un'esportazione

- **Source:** code: lib/ExportInterventiQuery.php:3-6 (class docblock) | **Fact:** «Builds the standard intervention-export dataset once, so the displayed count and the synchronous export cannot silently use different filters.»
- **Source:** code: lib/ExportInterventiQuery.php:9-29 (`select()`, `count()`, `joins()`) | **Fact:** `select()` is `SELECT interventi_eseguiti.* FROM interventi_eseguiti` and `count()` is `SELECT COUNT(*) AS totale FROM interventi_eseguiti`; both add the same `joins()` and the same `where()`. Joins: `LEFT JOIN interventi ON interventi.id_intervento=interventi_eseguiti.id`, `LEFT JOIN carichi ON carichi.id=interventi.id_carico`, `LEFT JOIN carichi_righe ON carichi_righe.id_utenza=interventi.id_utenza AND carichi_righe.id_carico=interventi.id_carico`, `LEFT JOIN utenti ON utenti.id=interventi.id_utenza`. One row of the file = one row of `interventi_eseguiti` (one esecuzione). The utenze table in code is `utenti`.
- **Source:** code: lib/InterventoEseguitoBase.php:331-343 (`getForExport()`, `countForExport()`) | **Fact:** the base class `getForExport($request, $conta = false)` returns the count when `$conta` is true, otherwise the rows of `ExportInterventiQuery::select($request)`.
