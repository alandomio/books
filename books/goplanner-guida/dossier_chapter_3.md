### C. Come l'importazione tratta un'utenza già presente (A3 — decisivo)

- **Source:** code: `lib/UtenzaBase.php` (`UtenzaBase::getId`), `lib/Utenza.php` (`Utenza::getId`) | **Fact:** un'utenza importata si riconosce **per codice su tutta la commessa**: `SELECT * FROM utenti WHERE codice='…' ORDER BY id DESC LIMIT 1` (la più recente con quel codice). 49 commesse ridefiniscono `getId` nel proprio `custom/<commessa>/php/Utenza.php` (conteggio con `git grep`, 25/11/2026): la regola «per codice» è quella comune, non universale.
- **Source:** code: `lib/ImportazioneReimportazione.php` (intestazione e `importaRiga`, GOP-480) | **Fact:** ogni riga del file cade in uno di sei casi: **NUOVA** (codice mai visto: si crea la pratica nella lista), **APERTA** (già presente, aperta, senza appuntamento: si aggiornano i dati pieni del file e la pratica passa nella lista nuova; la riga della lista vecchia si segna `carichi_righe.sostituita_da`), **CON_APPUNTAMENTO** (appuntamento da svolgere: resta com'è, si aggiornano solo le note), **CONCLUSA** (eseguita, non fattibile, controllata, inviata o annullata: «si crea una pratica nuova con lo stesso codice nella lista; lo storico della vecchia resta»), **ANNULLATA** (il file porta lo stato ANNULLATA), **RIPETUTA** (stesso codice più in alto nello stesso file: vale la prima riga).
- **Source:** code: `lib/ImportazioneReimportazione.php` (`creaPratica`, commento «NUOVA e CONCLUSA: una pratica nuova (riga nuova di utenti) nella lista»; `portaNellaLista`) | **Fact:** NUOVA e CONCLUSA creano una **riga nuova di `utenti`** (stato 1, importato); APERTA **riusa la stessa riga di `utenti`** e aggiunge la riga di `carichi_righe` nella lista nuova. Conseguenza: un file di N righe non produce per forza N utenze nuove; e la stessa utenza fisica può avere più righe di `utenti` con lo stesso codice (caso CONCLUSA).
- **Source:** code: `lib/ImportazioneEsecuzione.php` (intestazione, GOP-478) | **Fact:** con la pagina File › Importazione «la lista e' sempre nuova: non si aggiunge in silenzio a una lista con lo stesso nome di file»; una riga senza codice, con un codice già visto nel file o rifiutata dalla commessa si scarta e finisce nel resoconto con il motivo; un errore su una riga non ferma le altre.
- **Source:** wiki: `wiki/assistenza-clienti/import-carico.md` (passo 4) | **Fact:** in File › Importazione la scheda «Dati da importare» offre **lista nuova** (nome lista obbligatorio, lotto obbligatorio se la commessa ha dei lotti, scadenza facoltativa) oppure **lista esistente** (una lista aperta) con la scelta sui duplicati **ignora** (predefinito) o **sovrascrivi**; il **Codice** riconosce i duplicati. Triangolato con `lib/ImportazioneReimportazione.php` (`DUPLICATI_IGNORA`, `DUPLICATI_SOVRASCRIVI`, GOP-745). Dettaglio nel capitolo 4.
