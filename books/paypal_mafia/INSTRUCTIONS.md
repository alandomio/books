## Workflow: The Stateless Loop
1.  **Selection:** Scegli un solo Beat dal `PLAN.md`.
2.  **DSR Drafting:** L'Artigiano produce `draft_prose.md` poi `capitolo_X.md`.
3.  **System 2 Audit:** L'Editor valuta le NUFs (Score >= 8.5 richiesto).
4.  **Stop-Hook:** Se Fail, genera `feedback_loop.md` e reinietta l'errore nel prossimo loop stateless (Exit Code 2).
